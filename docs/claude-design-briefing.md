# 공부한입(StudyBite) 리디자인 브리핑 — 클로드 디자인용 선입력 문서

> 이 문서는 claude.ai(클로드 디자인)에서 웹사이트 리디자인 작업을 시작하기 전에,
> **첫 메시지로 통째로 붙여넣는** 용도입니다. 이 대화에서 만든 HTML/CSS(Tailwind) 목업을
> 이후 Claude Code로 가져와 실제 Next.js 프로젝트에 이식할 예정이므로, 여기 적힌 제약을
> 벗어난 결과물(예: 존재하지 않는 라이브러리, 다른 CSS 프레임워크)은 이식 단계에서 전부
> 다시 변환해야 해서 비효율이 생깁니다. 아래 내용을 전제로 디자인해 주세요.

---

## 1. 제품 개요

**공부한입 (StudyBite)** — 대학생을 위한 AI 학습 도우미 웹앱.
브랜드 컨셉: 강의 자료를 "한입 크기로 베어물어" 소화하기 쉽게 만들어준다는 뜻.
로고도 책을 한입 베어문 모양(Apple 로고 패러디 구도).

### 핵심 기능 (메뉴 = 정보구조의 뼈대)

| 메뉴 | 라우트 | 설명 |
|---|---|---|
| 노트/요약 | `/notes` | PDF/DOCX/필기사진 업로드 → (1) 2단 압축 요약, (2) 강의식 줄글 설명 두 종류를 독립적으로 생성. A4 문서 형태로 웹에 표시 + PDF 다운로드 |
| 예상문제출력 | `/exams` | 참고자료+기출문제 파일 업로드, 출제 성향/기출 반영강도(0~10) 입력 → AI가 예상 시험지 생성 → 웹에서 응시 → 자동/AI 채점 → 취약점 분석 |
| 오답노트 | `/review` | 시험에서 틀린 문제들을 복습 |
| AI선생님 | `/tutor` (목록) → `/tutor/[id]` (대화) | 업로드한 자료 기반 1:1 챗봇 |
| PDF 영어자료 변환 | `/translate` | 영어 PDF를 원본 레이아웃 유지한 채 한글 오버레이로 번역 (노트/시험과 완전히 분리된 별도 파일 풀) |
| 캘린더 | `/calendar` | 학습 일정 관리 |
| 집중 타이머 | `/timer` | 집중 타이머 (몰입 모드/심플 모드 두 뷰가 있음) |
| 장학금 | `/scholarships` | 장학금 정보 |
| 대외활동/공모전 | `/activities` | 대외활동·공모전 공고 매칭 (링커리어 스크래핑 기반) |
| 문의하기 | `/inquiries`, `/inquiries/mine` | 전체 사용자 문의 익명 게시판 |
| 요금제 | `/billing` | 토스페이먼츠 자동결제 구독 (무료/Pro) |
| 마이페이지 | `/profile` | 관심분야/전공 설정 + 자료 보관함(업로드 파일을 과목별로 관리) |
| 내 정보 | `/profile/account` | 계정 정보/비밀번호 변경/구독 요약/회원 탈퇴 |
| 관리자 (관리자 전용) | `/admin/inquiries`, `/admin/activities` | 문의/공모전 데이터 관리 |
| 인증 | `/login`, `/signup`, `/forgot-password`, `/reset-password` | 이메일/소셜 로그인 |
| 랜딩(비로그인) | `/` | 서비스 소개 |

**타겟 사용자**: 한국 대학생. 과제/시험 준비를 빠르게 처리하고 싶어함. 모바일보다 데스크톱/노트북 사용 비중이 높다고 가정하되 반응형은 필수.

## 2. 현재 디자인 상태 (리디자인 전)

지금 사이트는 **두 개의 서로 다른 스타일이 공존**하는 상태입니다. 이번 리디자인 범위는
**랜딩 + 로그인 후 대시보드 전체**이며, **하나의 일관된 브랜드 톤으로 통일**하는 것이 목표입니다.

- **랜딩페이지(`/`)**: 다크 배경 위 글래스모피즘. 실사 배경 이미지(공부 책상 씬) 위에
  반투명 유리 패널을 얹는 방식. 브랜드 컬러는 라임그린 계열 accent(`#cbff4d`)+오프화이트
  텍스트(`#f6f3ec`)+짙은 브라운블랙 배경(`#12100c`). 로고 우상단을 물어뜯은 자리와 같은
  위치에 카드/이미지 프레임 모서리를 둥글게 도려내는 `.bite-corner` 시그니처 장치가 있음.
  전용 서체로 Do Hyeon(제목), Gothic A1(본문)을 씀.
- **로그인 후 대시보드(`/notes`, `/exams` 등 전체)**: 위 브랜드 톤이 전혀 적용되지 않은
  **매우 단순한 회색조 미니멀 스타일**(흰 배경, `gray-200` 보더, `gray-500~900` 텍스트,
  기본 Geist 서체). 사실상 디자인이 없는 상태에 가까움 — 이번 작업으로 새로 세워야 하는 영역.

**이번 리디자인에서 기대하는 방향**: 랜딩의 브랜드 무드(다크/글래스모피즘/라임 accent/한입
모티프)를 그대로 대시보드까지 끌고 갈지, 아니면 대시보드는 실사용성 위주의 밝은 톤으로 가고
랜딩과는 "같은 브랜드지만 다른 register"로 분리할지는 **디자인 논의로 정해도 됨** — 다만
로고와 브랜드 컬러/타이포 아이덴티티(아래 3번)는 두 영역에서 반드시 동일하게 유지해야 함.

## 3. 절대 지켜야 할 브랜드 규칙

- **로고 모양은 반드시 SVG `<mask>` 방식으로 도려낸 원**이어야 함 (`fill-rule="evenodd"`로
  구현하면 모서리를 물었을 때 바깥으로 튀어나온 영역이 잘못 채워지는 버그가 있었음 — 이미
  검증되어 고정된 구현이므로 로고 자체의 모양/비율은 변경하지 말 것, 색상 적용 방식만
  디자인 대상).
- "한입 베어문" 모티프(우상단을 원형으로 물어뜯은 실루엣)는 로고뿐 아니라 카드/이미지
  프레임 등에도 반복 적용되는 **구조적 브랜드 장치**임 — 리디자인에서도 이 모티프를
  유지하거나 발전시키는 방향을 권장.
- 브랜드명은 항상 "공부한입" (영문 병기 시 StudyBite).

## 4. 기술 스택 제약 — 산출물이 반드시 지켜야 할 것

Claude Code로 이식할 때 그대로 옮겨 붙일 수 있어야 하므로, 아래 스택 **밖의 것을 쓰지 말아주세요**.

- **Tailwind CSS v4** (`@tailwindcss/postcss`, `@theme inline` 방식의 CSS-first 설정).
  Tailwind v3 문법이나 `tailwind.config.js` 기반 설정을 전제로 한 클래스/플러그인은 피할 것.
- **컴포넌트 라이브러리 없음** — shadcn/ui, Radix, MUI, Chakra 등 **아무 UI 라이브러리도
  설치되어 있지 않음**. 버튼/모달/드롭다운/토스트 등은 전부 순수 Tailwind 유틸리티 클래스 +
  약간의 커스텀 CSS로 손으로 만든 것. 새 디자인도 이 전제로 — 즉 "shadcn 스타일"의 컴포넌트를
  그려도 되지만 실제로 shadcn을 쓴다고 가정하지 말고 마크업/클래스 자체로 완성해줄 것.
- **아이콘: Phosphor Icons** (`@phosphor-icons/react`)를 일부 화면에서 쓰고 있고, 나머지는
  인라인 SVG를 직접 그려 씀. 새 아이콘이 필요하면 Phosphor Icons 세트에서 고르거나(이름을
  명시해주면 이식 시 그대로 매핑 가능), 심플한 outline 스타일의 인라인 SVG로.
- **폰트**: `Geist`(기본 sans, 영문/숫자), `Geist Mono`, `Do Hyeon`(랜딩 제목용, 한글 지원
  Google Fonts), `Gothic A1`(랜딩 본문용 한글, weight 400/500/700/900)이 이미 `next/font/google`로
  등록되어 있음. 새 서체가 필요하면 **Google Fonts에 있는 것**으로 제안해줄 것(라이선스 없는
  외부 폰트는 이식 불가). 한글 대응이 꼭 필요함 — 본문은 대부분 한글임을 항상 염두에 둘 것.
- **다크모드**: 현재 대시보드는 다크모드 미지원(라이트 고정), 랜딩만 애초에 다크 고정 배경.
  시스템 다크모드 대응 여부는 디자인 논의로 정해도 되나, 정한다면 명시적으로 알려줄 것.
- **반응형 필수**: 모바일에서도 깨지지 않아야 함 (실제 사용자 다수가 모바일로도 접속).
- React 19 / Next.js 16 App Router 기반 실제 앱으로 옮겨 붙일 것이므로, 정적 HTML목업이라도
  **실제 데이터가 들어갈 자리(파일 목록, 시험 문항, 채팅 말풍말, 표 등)는 리스트/반복
  구조가 명확히 드러나게** 만들어 줄 것 — 정적으로 하드코딩된 카드 3개가 아니라 "카드가
  N개 반복되는 패턴"이라는 게 한눈에 보이는 구성으로.

## 5. 산출물 형식 (이번 작업에서 원하는 것)

- **정적 HTML + Tailwind 클래스**로 화면별 목업을 Artifact로 만들어 주세요. React/JSX 문법이
  아니라 순수 HTML이어도 됩니다 (Claude Code에서 React 컴포넌트로 변환하는 건 제가 처리합니다).
- 화면 하나당 Artifact 하나 정도의 단위 권장 (예: 랜딩페이지, 대시보드 공통 네비게이션,
  노트 목록/상세, 시험 응시 화면, AI선생님 채팅, 마이페이지 등).
  **먼저 디자인 시스템(색상 팔레트, 타이포 스케일, 버튼/카드/폼 기본 컴포넌트)을 한 장으로
  정의**하고, 그다음 개별 화면에 적용하는 순서를 권장합니다 — 화면마다 톤이 흩어지는 걸 방지.
- 실제 콘텐츠는 위 1번 기능 설명을 참고해 한국어로 그럴듯한 더미 데이터를 채워주세요
  (예: 노트 제목은 "전공수학 3주차 요약" 같은 식).

## 6. 참고 — 리디자인 범위 밖 (건드리지 않아도 되는 것)

- 인증/결제/사용량 제한 등 백엔드 로직, 라우팅 구조, DB 스키마는 이번 디자인 작업과 무관.
  화면 레이아웃/스타일/컴포넌트 디자인에만 집중하면 됩니다.
- 관리자 페이지(`/admin/*`)는 우선순위 낮음 — 필요하면 나중에.

## 7. 이번 세션에서 정할 것

1. 대시보드에도 랜딩의 다크/글래스모피즘 톤을 가져갈지, 밝은 톤으로 새로 세울지
2. 위 결정을 반영한 **디자인 시스템 1장** (색상/타이포/기본 컴포넌트)
3. 공통 네비게이션(현재 상단 가로 메뉴 + 드롭다운 구조) 리디자인
4. 화면별 목업 (우선순위: 랜딩 → 대시보드 공통 셸/네비 → 노트 → 시험 → AI선생님 → 나머지)
